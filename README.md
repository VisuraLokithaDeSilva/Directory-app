# 📖 Sri Lanka Parliament Members Directory

![Project Status](https://img.shields.io/badge/Status-Active-brightgreen)
![Tech Stack](https://img.shields.io/badge/Tech-HTML%20%7C%20CSS%20%7C%20JS-blue)

A comprehensive, searchable digital directory for Members of Parliament (MPs) in Sri Lanka. This web application allows users to quickly find contact information, addresses, and portfolios of MPs through a responsive and user-friendly interface.

## 🌟 Features

* **Dual Search Modes:**
    * **By Name:** Filter MPs by their name.
    * **By Title:** Search based on ministerial portfolios or positions (e.g., "Minister of Health", "Speaker").
* **Auto-Complete Suggestions:** Real-time suggestions appear as you type for faster navigation.
* **Detailed Member Profiles:** Displays comprehensive data including:
    * 📸 Profile Image
    * 📞 Contact Numbers (Mobile, Sitting, Non-Sitting)
    * 🏠 Addresses (Sitting & Non-Sitting)
    * 📧 Email & Fax
* **Integrated Navigation:** Direct link to the companion [Parliament Seat Finder App](https://sri-lanka-parliament-seat-finder.netlify.app/).
* **Mobile Responsive:** Optimized layout for phones, tablets, and desktops.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure.
* **CSS3:** Custom maroon-themed styling (`#800000`), responsive grid layouts, and background effects.
* **JavaScript (Vanilla):** efficient search algorithms, DOM manipulation, and dynamic data rendering.
* **Analytics:** Integrated with Microsoft Clarity for user behavior insights.
